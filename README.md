# Task Manager (To-Do List) ✅

## Project Overview
The *Task Manager* is a high-performance CRUD (Create, Read, Update, Delete) application built to help users streamline their daily productivity. This project focuses on efficient data handling and providing a seamless user experience.

## Why I Built This
I wanted to solve the common problem of losing "To-Do" items upon refreshing a browser. This project allowed me to master *Web Storage APIs* and complex *DOM Manipulation*, ensuring that the application is both functional and reliable for daily use.

## Key Features
* *Data Persistence:* Integrated *LocalStorage* to ensure that all user tasks remain saved even after the browser is closed or refreshed.
* *Dynamic Date Categorization:* Implemented JavaScript logic to automatically categorize tasks into "Today," "Yesterday," or "Other" based on entry dates.
* *Real-Time UI Updates:* Users can add, mark as complete, or delete tasks with instant visual feedback without page reloads.
* *Responsive Design:* A clean, mobile-first interface that adapts to various screen sizes using CSS Flexbox.

## Technical Skills Applied
* *JavaScript (ES6+):* Advanced DOM manipulation, Event Listeners, and LocalStorage integration.
* *HTML5:* Semantic structure for better SEO and accessibility.
* *CSS3:* Custom animations, hover effects, and responsive layout design.

## How to Run
1. Clone the repository.
2. Open index.html in your browser.
